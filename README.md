# The Morse Microwave — One-Sentence Absurd Invention Pitch

A one-sentence pitch for a ridiculous invention that fixes a tiny everyday
annoyance: a microwave that beeps in Morse code to tell you exactly which
corner of your soup is still cold, so you stop playing hot-spot roulette
with your lunch.

`main.py` (pure Python standard library) writes the pitch to
`/output/entry.txt`.
